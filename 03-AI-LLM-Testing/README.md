# AI and LLM Testing

## Project Overview
This project focuses on testing Generative AI applications and Large Language Models (LLMs).

The sample application is a legal AI assistant that generates answers based on user questions and legal documents.

## Objectives
- Validate AI-generated responses.
- Identify hallucinations.
- Validate prompt and response accuracy.
- Verify contextual understanding.
- Evaluate response relevance and consistency.
- Test responsible AI behavior.

## Technologies
- Python
- Playwright
- OpenAI API / Azure OpenAI
- LangChain
- LLM Evaluation
- Prompt Engineering

## Test Scenarios
1. Validate accurate responses for legal queries.
2. Verify incorrect or misleading AI responses.
3. Test prompt injection attacks.
4. Validate responses for ambiguous questions.
5. Verify context retention.
6. Test unsupported questions.
7. Validate response consistency.
8. Measure response latency.

## Key Evaluation Metrics
- Answer Relevance
- Faithfulness
- Context Precision
- Context Recall
- Hallucination Rate
- Response Latency

## Expected Deliverables
- Prompt test datasets
- LLM evaluation scripts
- AI response validation reports
- Hallucination analysis
- AI quality metrics
